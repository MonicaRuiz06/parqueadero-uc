# parqueadero-uc

La universidad quiere digitalizar el control de un parqueadero pequeño de 30 cupos. El parqueadero atiende a tres tipos de usuario: estudiantes, docentes y visitantes, cada uno con tarifas y reglas de acceso distintas.

El programa debe simular un día de operación: registrar la entrada de vehículos, calcular los cobros, aplicar descuentos (por ejemplo, por horario nocturno) y llevar estadísticas de ocupación e ingresos.
